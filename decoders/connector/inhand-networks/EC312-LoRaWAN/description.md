EC312-LoRaWAN is an industrial LoRaWAN edge computer with a built-in ChirpStack LoRaWAN Network Server.

Use this connector for LoRaWAN end-devices connected through an EC312-LoRaWAN edge computer. Uplinks reach TagoIO through the LoRaWAN ChirpStack network integration; this connector normalizes the raw frame payload to hexadecimal and passes the remaining variables through unchanged.
